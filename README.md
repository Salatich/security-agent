# ForeSight Security & Quality Agent — PR UX Sandbox

Демо-репозиторий для сравнения двух вариантов доставки авто-фиксов (SonarQube + Veracode) в GitHub Pull Requests:

- **Вариант Б (PR Suggestions + Дочерний PR `ai-fix/*` в фича-ветку)** — без прямого авто-пуша бота в рабочую ветку разработчика.
- **Вариант В (ChatOps `/fix`)** — агент публикует отчёт и превью диффа, а коммит в ветку PR делает только после команды `/fix` от разработчика.
